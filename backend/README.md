# Backend — Telegram Stars + Чёрный рынок

1. Скопируйте `config.example.php` в `config.php` и впишите токен бота и длинный `webhook_secret`.
2. Разместите папку `backend/` на том же HTTPS-домене, где работает Mini App. PHP должен иметь право записи в `backend/data/`.
3. Установите webhook бота на `https://ВАШ-ДОМЕН/backend/telegram_webhook.php`, передав тот же `secret_token`, что указан в конфиге.
4. Магазин Stars использует `createInvoiceLink` с валютой `XTR`. Награда выдаётся только после `successful_payment` и отдельного `stars_claim.php`.
5. Чёрный рынок авторизует игрока по проверенному `Telegram.WebApp.initData`; 5 активных лотов, для серверно подтверждённого Premium — 10. После продажи продавец получает 95% цены при следующем открытии рынка; с серверно подтверждённым Premium — 97%.

## Важно для полноценного релиза
Текущая игра исторически хранит Дженни и инвентарь в `localStorage`. Поэтому общий рынок уже работает между Telegram-пользователями, но экономика предметов/Дженни всё ещё доверяет клиенту и не является античит-системой. Для коммерческого релиза нужно перенести баланс Дженни, владение предметами и инвентарь на сервер и проводить покупку одной серверной транзакцией. Stars-платежи в этом обновлении, напротив, подтверждаются сервером через Telegram webhook.

Не добавляйте `config.php` с токеном в публичный репозиторий.
