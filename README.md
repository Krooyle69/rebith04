# Перерождение: Начало — v50

Офлайн/local-версия RPG.

## Новое в v50
- Система сундуков за успешное прохождение подземелий.
- 5 уровней сундуков: обычный, редкий, эпический, легендарный, мифический.
- Открытие сундуков с золотом, теневыми монетами, осколками и шансом на дополнительный лут.
- Титулы получили постоянные боевые бонусы. Активный титул влияет на характеристики персонажа.
- Добавлена отдельная сюжетная линия из 8 последовательных квестов.
- Сюжетные задания имеют собственные награды и визуальную временную шкалу.
- Добавлены локальные PNG-иконки для сундуков и сюжетных квестов.
- Сохранения старых версий сохраняются и мигрируют в новую структуру.

## Запуск
Открой `index.html` в браузере. Сервер не требуется для локального режима.
