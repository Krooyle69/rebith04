### Требования к изображениям

- Формат: PNG.
- Для предметов экипировки используется имя `класс_тип.png`.
- Для артефактов используется `artifact_0.png` — `artifact_3.png`.
- Не переименовывайте файлы после добавления.

Код автоматически выбирает правильную картинку по классу, типу экипировки и варианту артефакта. Для уже существующих сохранений добавлена привязка старых артефактов к соответствующему изображению по названию.
