# Перерождение: Начало — v40

## Что изменено
- Универсальная замена отображаемых emoji на локальные PNG-иконки во всех экранах, включая динамические элементы.
- Иконки ресурсов, опыта, золота, теневых монет, энергии, HP, характеристик, магазина, рейтинга, достижений, почты, заданий и боевых сообщений.
- Сохранение переведено на новую версию `v40`.
- Загрузка выбирает самый свежий сохранённый слот по `_savedAt` из текущего и резервных/старых ключей.
- Добавлена миграция без удаления неизвестных полей: новые механики не должны теряться при обновлении.
- После загрузки состояние нормализуется и сразу создаётся актуальный v40 save + backup.
- Автосохранение после click/change/input, при скрытии страницы, pagehide/beforeunload и каждые 500 мс сохранено.
- Игровая механика, баланс и существующие функции не изменялись.

## Откат
`Rebirth_v38_rollback.zip` — исходная версия до иконок.
`Rebirth_v39_icons_rollback.zip` — предыдущая иконковая версия.
